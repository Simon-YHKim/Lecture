## Line 5 — 치수 기입과 출도 · DEMO-01 화면 녹화 (Frame 5)

> 이 구간은 화면 녹화입니다. 아래 17단계를 **순서대로 빠짐없이** 수행하면서 말합니다.

### 1단계 — 지난 파일 열기

    AutoCAD를 켭니다. `OPEN` 입력하고 엔터. 또는 Ctrl+O.
    지난 시간에 저장한 파일을 고릅니다. 아이들러 풀리 브래킷을 6차시까지 그려 둔 파일이에요. 열기를 누릅니다.
    (`EDU-IB-02_L06_REPRESENTED.dwg`)
    새로 만들지 않습니다. 형상이 다 들어 있는 그 파일 위에 오늘 치수를 올립니다.
    `Z` 엔터, `A` 엔터. 줌 전체입니다. 도면틀까지 화면에 들어옵니다.

### 2단계 — 기본 설정 확인 · 스냅과 직교

    F3을 눌러 객체 스냅이, F8을 눌러 직교가 켜져 있는지 봅니다.
    `OS` 입력하고 엔터. 오늘 쓰는 끝점·중심·사분점·교차점에 체크가 있는지 봅니다.
    좌표를 외워서 치는 것보다 형상 위의 점을 직접 집는 게 안전합니다.
    형상이 조금이라도 틀려 있으면 값이 그 자리에서 다르게 나와요. 바로 알아차립니다.

### 3단계 — 치수선 레이어를 현재 레이어로

    `LAYER` 입력하고 엔터. 레이어 특성 관리자가 열립니다.
    `치수선` 행을 선택하고 현재로 설정 버튼을 누릅니다. 대화상자를 닫습니다.
    화면 위 레이어 표시가 치수선으로 바뀌었는지 봅니다. 흰색 7번입니다.

    왜 치수를 넣기 전에 이걸 먼저 할까요.
    치수를 다 넣고 옮기려면 넣은 치수를 전부 골라내야 합니다.
    치수가 외형선과 겹쳐 있어서 하나씩 집다 보면 형상선이 같이 잡힙니다.
    그리기 전에 한 번 바꾸는 게 훨씬 낫습니다.

    레이어를 나눠 두면 나중에 치수만 끄고 형상만 볼 수 있어요.
    설비가 들어갈 자리를 도면에서 확인할 때 이렇게 씁니다.
    선이 덜 겹쳐야 동선과 간섭이 눈에 들어옵니다.

### 4단계 — 치수 스타일 새로 만들기

    `D` 입력하고 엔터. DIMSTYLE 명령입니다. 치수 스타일 관리자가 열립니다.
    지금 스타일 목록에는 ISO-25 하나만 있을 거예요.
    이걸 직접 고치지 않습니다. 새로 하나 만듭니다.
    원본을 남겨 두면 설정이 틀어졌을 때 비교할 데가 있어요.

    새로 만들기 버튼을 누릅니다.
    새 스타일 이름에 `EDU-A3` 입력합니다.
    시작 스타일은 ISO-25 그대로 둡니다. 이걸 바탕으로 시작한다는 뜻이에요.
    사용 위치는 모든 치수로 둡니다.
    계속 버튼을 누릅니다.

### 5단계 — 문자 · 화살표 · 자릿수를 정하고 현재로 지정

    새 치수 스타일 대화상자가 열립니다. 위에 탭이 일곱 개 있어요. 네 개만 손댑니다.

    문자 탭을 엽니다.
    문자 높이에 `5` 입력합니다.
    문자 색상은 도면층별로 둡니다. 레이어에서 이미 흰색 7번을 줬습니다.
    문자 배치는 수직 위, 수평 중심으로 둡니다. 치수선 위 가운데에 숫자가 앉습니다.

    기호 및 화살표 탭을 엽니다.
    화살촉 첫 번째를 닫힌 채움으로 둡니다. 두 번째는 첫 번째를 따라 바뀝니다.
    화살표 크기에 `5` 입력합니다. 문자 높이와 같은 값이에요.
    둘이 크게 어긋나면 치수 하나가 따로 놉니다.

    맞춤 탭을 엽니다.
    오른쪽 아래 치수 피쳐 축척을 봅니다. 전체 축척 사용이 `1` 인지 확인합니다.
    여기가 1이 아니면 문자 높이 5가 그 배수로 커지거나 작아집니다.
    문자 높이를 아무리 고쳐도 화면 크기가 안 맞나요. 대개 이 값이 범인입니다.

    1차 단위 탭을 엽니다.
    단위 형식은 십진입니다. 정밀도는 소수점 `0` 자리로 둡니다.
