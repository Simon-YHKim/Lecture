# SCRIPT — AutoCAD Technician Lesson 05

**Voice:** 사용자 직접 녹음<br>
**Voice direction:** 화면 위치를 명확히 지시하는 실습 강사 톤. `위`, `오른쪽`, `같은 축`, `선종류`를 짧게 강조한다.<br>
**Continuity:** `EDU-SB-01 · L04_PRIMARY_FEATURES → L05_THIRD_ANGLE_VIEWS`<br>
**Paper / projection:** `A3 landscape · third-angle`<br>
**Layers used:** `OUTLINE`, `CENTER`, `HIDDEN`, `CONSTRUCTION`

> 실제 음성 도착 후 Whisper 단어 타임코드로 투영선과 녹화 타이밍을 동기화한다. 회사 도면이나 캡처는 사용하지 않는다.

## Line 1 — L04 정면도를 제3각법 기준 뷰로 고정한다 (Frame 1)

**Time:** 00:00–01:00<br>
**화면 지시:** EDU-SB-01과 체크포인트, 제3각법 위치, 네 Layer를 한 화면에 제시한다.

    다섯 번째 수업은 L04_PRIMARY_FEATURES에서 계속합니다. 중앙 Ø20, AF30 육각 포켓, 상부 러그와 장공 Seed, 좌측 14×14 국소 얕은 포켓 경계가 들어간 정면도를 기준 뷰로 사용합니다. 이번 시간에는 이 정면도를 다시 그리지 않고 제3각법에 따라 평면도를 위에, 우측면도를 오른쪽에 투영합니다.

    OUTLINE은 보이는 외형, CENTER는 원과 대칭 특징의 중심, HIDDEN은 다른 방향에서 가려지는 구멍과 포켓, CONSTRUCTION은 투영과 보조선에 사용합니다. 객체는 ByLayer를 유지합니다. 완료 파일은 L05_THIRD_ANGLE_VIEWS이며 다음 차시의 반복 특징 배치 기준이 됩니다.

    시험에서는 3D 모델, 치수, 지시사항을 제한시간 안에 해독해야 합니다. 이 과정은 제3각법을 사용하지만 실제 시험 문제지의 투상법과 배치 지시를 먼저 확인하십시오. 뷰 위치가 뒤바뀌거나 선종류와 Layer가 맞지 않으면 감점 위험이 있습니다.

## Line 2 — 평면도는 위, 우측면도는 오른쪽에 투영한다 (Frame 2)

**Time:** 01:00–03:30<br>
**화면 지시:** 정면도를 하단 좌측에 고정하고 평면도 위, 우측면도 오른쪽 배치를 투영선으로 조립한다.

    제3각법에서 정면도는 기준 뷰입니다. 평면도는 정면도 위에, 우측면도는 정면도 오른쪽에 놓습니다. 세 그림은 서로 다른 부품이 아니라 같은 EDU-SB-01의 폭, 높이, 깊이를 나누어 보여 주는 결과입니다.

    CONSTRUCTION Layer에 정면도의 주요 끝점과 중심에서 수직 투영선을 올립니다. 본체 폭 80과 Datum B, X가 40인 중심축이 평면도에서도 같은 X 위치에 있어야 합니다. 우측면도에는 수평 투영선을 보내 높이 관계를 유지합니다. 깊이 8은 정면도만으로 보이지 않으므로 평면도와 우측면도에서 OUTLINE으로 표현합니다.

    Ø20 구멍은 정면도에서는 원이지만 다른 뷰에서는 두 평행한 HIDDEN 선으로 나타날 수 있습니다. 중심 위치는 CENTER로 연결합니다. AF30 포켓, 장공 Seed, 얕은 포켓 경계도 같은 방식으로 어느 선이 보이고 어느 선이 가려지는지 판단합니다. 투영선은 결과 외형이 아니라 위치를 옮기는 보조선이므로 CONSTRUCTION에 둡니다.

## Line 3 — 세 뷰를 전체·세부·전체로 탐색한다 (Frame 3)

**Time:** 03:30–06:20<br>
**화면 지시:** 제3각법 미니맵과 탐색 리듬을 보여 준 뒤 `DEMO-01 · USER RECORDING`으로 전환한다.

    세 뷰를 만든 뒤에는 확대와 이동 중에도 배치 관계를 잃지 않아야 합니다. 먼저 전체 화면에서 평면도가 위, 우측면도가 오른쪽에 있는지 확인합니다. 다음으로 한 특징을 확대하고, 확인이 끝나면 다시 전체 배치로 돌아옵니다.

    DEMO-01에서는 L04_PRIMARY_FEATURES를 열고 정면도를 기준으로 투영선을 만든 다음, 평면도와 우측면도의 외형을 배치해 L05_THIRD_ANGLE_VIEWS를 구성합니다. 화면을 확대할 때 현재 어느 뷰를 보고 있는지 미니맵으로 확인합니다. PAN은 형상을 움직이는 명령이 아니라 보는 위치만 바꾸므로 객체 좌표가 변하지 않아야 합니다. 제3각법 위치·뷰 정렬 오류는 시험 감점 위험입니다.

    녹화 마지막에는 전체 화면으로 돌아와 세 뷰의 중심축과 외곽 정렬을 확인합니다. OUTLINE과 CONSTRUCTION이 섞이지 않았는지도 Layer별로 점검합니다.

## Line 4 — Ø20·AF30·장공·포켓을 세 뷰에서 추적한다 (Frame 4)

**Time:** 06:20–09:20<br>
**화면 지시:** 네 특징에 동일 번호를 부여하고 외형선·중심선·숨은선을 연결한 뒤 `DEMO-02 · USER RECORDING`으로 전환한다.

    이제 L04에서 만든 특징을 세 뷰에서 추적합니다. 특징 1은 중앙 Ø20 구멍입니다. 정면도의 원 중심에서 평면도와 우측면도로 투영해 CENTER 축을 맞추고, 가려지는 모서리는 HIDDEN으로 표시합니다.

    특징 2는 AF30 육각 포켓입니다. 정면도의 육각형이 다른 뷰에서는 포켓 깊이를 나타내는 외형선 또는 숨은선으로 바뀝니다. 특징 3은 상부 러그와 폭 8 장공 Seed입니다. 장공은 TOP과 RIGHT에서 두 HIDDEN 경계와 그 사이 CENTER로 나타납니다. 특징 4는 좌측 `(5,15)–(19,29)`, 깊이 2의 국소 얕은 포켓 경계입니다. 단순히 정면도 선을 복사하지 않고 깊이와 가시성을 판단합니다.

    모션 그래픽의 TOP과 RIGHT는 얇은 두께를 읽기 쉽게 과장한 NTS 개념도입니다. 실제 AutoCAD 녹화와 작도에서는 Model Space 1:1의 동일 축척으로 TOP 80×8, RIGHT 8×50을 유지합니다. DEMO-02에서는 앞 장면에서 만든 세 뷰의 같은 번호를 커서로 추적합니다. 각각의 위치, CENTER, 보이는 OUTLINE, 가려지는 HIDDEN을 확인해 L05_THIRD_ANGLE_VIEWS를 완성합니다. 한 뷰에서 판단하기 어렵다면 추측하지 말고 다른 뷰와 3D 모델의 지시를 다시 봅니다. 중심선·숨은선·Layer 누락은 시험 감점 위험입니다.

## Line 5 — 네 Layer로 세 뷰의 누락 정보를 검수한다 (Frame 5)

**Time:** 09:20–12:15<br>
**화면 지시:** 특징 대응표와 20초 생각 시간을 제공한 뒤 정답 투영선과 Layer 검수표를 공개한다.

    화면의 대응표를 완성해 보겠습니다. 정면도의 원은 다른 뷰에서 어떤 선이 되는가. 포켓 깊이는 어느 뷰에서 확인하는가. 장공의 중심축은 어디까지 이어지는가. 얕은 포켓 경계 중 가려지는 부분은 HIDDEN인가 OUTLINE인가를 적어 보세요.

**화면 지시:** 20초 동안 나레이션을 비우고 `L04 특징을 세 뷰에 연결`과 진행 막대만 유지한다.

    정답을 확인합니다. 보이는 외곽은 OUTLINE, 원과 대칭축은 CENTER, 가려지는 구멍과 포켓은 HIDDEN, 위치를 전달한 투영선은 CONSTRUCTION입니다. 투영선과 최종 외형을 같은 Layer에 두면 검수가 어려워집니다. 세 뷰에서 Datum B 중심축과 본체 폭, 높이, 깊이가 정렬되는지 측정합니다.

    뷰가 비슷해 보인다는 이유로 통과하지 않습니다. 제3각법 위치, 축 정렬, 같은 특징의 대응, 선종류와 Layer를 모두 설명할 수 있어야 합니다.

## Line 6 — L05_THIRD_ANGLE_VIEWS로 저장한다 (Frame 6)

**Time:** 12:15–13:00<br>
**화면 지시:** 세 뷰와 체크포인트를 고정하고 시험 감점 위험과 다음 차시 반복 특징을 연결한다.

    EDU-SB-01의 정면도, 평면도, 우측면도가 연결되었습니다. 평면도는 위, 우측면도는 오른쪽에 있고 세 뷰의 중심축이 정렬되어야 합니다. OUTLINE, CENTER, HIDDEN, CONSTRUCTION 객체가 올바른 Layer에 있는지 확인합니다.

    시험에서는 제3각법 배치 오류, 중심선과 숨은선 누락, 지정 선종류·색상 불일치, 축척과 지시사항 불이행이 감점 위험입니다. 실제 감점 기준은 공식 문제지와 최신 공지가 우선합니다.

    파일을 L05_THIRD_ANGLE_VIEWS로 저장합니다. 다음 차시는 이 세 뷰의 Seed 특징과 중심축을 그대로 사용해 COPY, MIRROR, ARRAY로 반복 구멍을 배치합니다.
