# SCRIPT — AutoCAD Technician Lesson 03

**Part:** `EDU-SB-01 교육용 센서 장착 브래킷`<br>
**Checkpoint:** `L02_SETUP → L03_BASE_PROFILE`<br>
**Voice:** 사용자 직접 녹음<br>
**Voice direction:** 기준점과 입력값을 먼저 말하고 클릭 직전에 쉰다. 이번 차시에 추가되는 `OUTLINE`은 마젠타로, 유지되는 A3 설정은 회색으로 설명한다.

> 목표 길이는 12분입니다. 실제 나레이션과 화면 조작이 들어오면 단어 타임코드를 최종 기준으로 사용합니다.

## Line 1 — L02_SETUP에서 정면도를 시작한다 (Frame 1)

**Time:** 00:00–01:00

    세 번째 수업은 새 파일이 아니라 지난 시간의 L02_SETUP에서 시작합니다. A3 가로 도면틀, 표제란, 전체 Layer, 제3각법 배치 자리가 준비된 상태에서 EDU-SB-01의 기준 정면 외곽을 만듭니다. 오늘 종료 상태는 L03_BASE_PROFILE입니다.

    이번 차시에는 OUTLINE과 CONSTRUCTION만 사용합니다. CONSTRUCTION은 원점과 Datum, 80 곱하기 50 기준 상자, 러그 위치를 잡는 보조선입니다. OUTLINE은 최종적으로 보이는 정면 윤곽입니다. 시험에서는 지정 Layer와 제3각법 배치를 지키지 않으면 감점 위험이 있습니다.

## Line 2 — LINE과 PLINE을 제작 역할로 선택한다 (Frame 2)

**Time:** 01:00–03:30

    LINE은 개별 보조선과 러그 위치선처럼 한 선씩 관리할 때 사용합니다. PLINE은 연결된 외곽을 하나의 객체로 관리할 때 사용합니다. 오늘은 CONSTRUCTION Layer에서 LINE으로 기준을 만들고, OUTLINE Layer에서 PLINE으로 본체 외곽을 작성합니다.

    DEMO-01 · USER RECORDING에서는 같은 짧은 골격을 LINE과 PLINE으로 비교한 뒤 실제 EDU-SB-01 작업 파일로 돌아옵니다. 객체 수, 현재 Layer, 시작점과 끝점 연결을 확인합니다. 독립 예제는 선택 기준만 설명하고 최종 결과는 같은 누적 부품에 적용합니다.

## Line 3 — 원점과 두 Datum을 좌표로 고정한다 (Frame 3)

**Time:** 03:30–06:00

    원점은 본체 좌측 하단 0,0입니다. Datum A는 이 점을 지나는 하단 수평선이고 Datum B는 X가 40인 수직 중심선입니다. 먼저 현재 Layer를 CONSTRUCTION으로 전환합니다.

    원점에서 상대 입력 골뱅이 80,0과 골뱅이 0,50을 사용하면 가로와 세로 방향을 재현할 수 있습니다. X 40 위치에는 수직 중심선을 만들고, 러그와 경사면의 기준 위치도 보조선으로 표시합니다. 숫자를 입력하기 전에 원점 기준인지 현재점 기준인지 말합니다.

    A3 도면틀과 표제란은 BORDER와 TITLE Layer에 그대로 유지합니다. 지금 변경하는 것은 모델 영역의 CONSTRUCTION뿐입니다.

## Line 4 — 80×50 기준 상자와 정면 외곽을 작성한다 (Frame 4)

**Time:** 06:00–08:30

    CONSTRUCTION Layer에서 좌측 하단 원점을 첫 모서리로 선택하고 80 곱하기 50 기준 상자를 만듭니다. 이 상자는 최종 외곽의 전체 폭과 높이를 검수하는 틀입니다.

    이제 OUTLINE으로 전환합니다. PLINE을 시작해 `(0,0)`, `(0,35)`, `(25,35)`, `(40,50)`, `(55,35)`, `(68,35)`, `(80,23)`, `(80,0)`을 차례로 입력하고 CLOSE합니다. 아직 원호, R5, C5를 완성하지 않습니다. 다음 차시에서 `(25,35)–(40,50)–(55,35)`를 중심 `(40,35)`의 R15 원호로 바꾸고, 이후 `(68,35)` 어깨와 `(80,0)` 하단을 R5와 C5로 마감할 직선 골격입니다.

    DEMO-02 · USER RECORDING에서는 A3 도면틀·표제란·여덟 Layer가 준비된 `L02_SETUP`을 열되 Model Space 정면도 작업 영역은 빈 상태에서 시작합니다. 먼저 CONSTRUCTION을 현재 Layer로 두고 원점 `(0,0)`, Datum A, Datum B `X=40`, 80×50 기준 상자를 직접 만듭니다. 이어 OUTLINE으로 전환해 위의 여덟 PLINE 꼭짓점을 입력하고 CLOSE합니다. LIST 또는 Properties로 좌표와 닫힘을 확인하고, 결과가 A3 제3각법 정면도 자리에 놓였는지 확인합니다.

## Line 5 — 러그 골격과 폐곡선 상태를 검수한다 (Frame 5)

**Time:** 08:30–11:00

    상부 러그의 직선 골격과 우측 경사면 기준을 확인합니다. 다음 차시에서 원과 호를 추가할 접점이 정확한 보조선 위에 있어야 합니다. 필요 이상으로 선을 지우지 않고, 다음 특징의 중심과 접점을 만들 CONSTRUCTION은 유지합니다.

    OUTLINE은 하나의 연속 객체인지, 시작점과 끝점이 연결되었는지, 전체 80×50 기준을 벗어나지 않는지 확인합니다. 열린 경계나 잘못된 Layer는 다음 Hatch와 수정 단계에서 문제를 만듭니다.

    DEMO-03 · USER RECORDING에서는 객체 선택, Closed 상태, OUTLINE·CONSTRUCTION 속성, 원점·Datum, 80×50 측정값을 확인합니다. 시험에서 외관선·표제란·Layer·축척 또는 뷰 위치가 잘못되면 감점 위험이므로 현재 상태도 함께 점검합니다.

## Line 6 — L03_BASE_PROFILE로 저장한다 (Frame 6)

**Time:** 11:00–12:00

    오늘은 L02_SETUP을 그대로 이어받아 EDU-SB-01의 정면도 기준 골격을 만들었습니다. CONSTRUCTION에는 원점, Datum A, Datum B, 80×50 기준 상자와 러그 위치가 있고, OUTLINE에는 연결된 본체 정면 외곽이 있습니다.

    원·호·구멍·육각 포켓·장공과 Offset 경계는 아직 만들지 않습니다. 현재 상태를 L03_BASE_PROFILE로 저장합니다. 다음 차시에서는 같은 파일을 열어 CENTER와 OUTLINE을 사용해 중앙 Ø20, AF30, 러그 원호와 22×8 장공, 좌측 국소 포켓 경계를 추가합니다. 2×Ø6 장착 구멍과 3×Ø4 PCD 패턴은 L06에서 이어서 만듭니다.

    시험에서는 문제지와 감독 지시가 과정 기본값보다 우선합니다. Layer, 용지, 축척, 제3각법 또는 지시사항 불이행은 감점 위험이므로 체크포인트마다 다시 확인합니다.
