## 2026-09-14 / 대본 통합 검수 영상·릴리즈 제작 중

- 사용자가 국문·영문 강의 자료 전체와 검수용 MP4 제작, GitHub Release 게시를 명시적으로 위임했다. 이 범위의 commit·push·release에 재승인을 요청하지 않는다. 브랜치는 `feat/clone-voice-pipeline`이며 이전 변경을 보존한다.
- 현재 작업 정본은 Git 제외 `local-materials/release-review-current.json`이다. 여기의 `base`에 계획·제작 도구, `private`에 렌더 프로젝트·검사 로그·출력 파일을 둔다. 이전 `script-apply-current.json`은 승인 대본·음성 작업 기록으로 보존한다.
- **영상 제작 진행 중이며 GitHub에는 비공개 초안만 있다.** 원본 장면 검사 170개가 모두 통과했다. 현재 국문 1·7·8차시와 영문 1~5차시 총 8개 MP4가 자막 내용·시각 왕복, 전체 디코딩, 장면별 음성·화면 대조를 통과했다. 국문 7차시의 측정값 자리표시 자막도 바로잡고 음성·화면 검증을 마쳤다. 영문 도면 8개 프레임의 16개 주석은 현행 영문 표기로 변환했으며 도형·대본·음성·시각은 동일하다.
- 영상의 도면 글자 누락이라는 초기 판독은 원본 MP4 재추출로 철회했다. 해당 글자는 실제로 존재한다. 별도 두 장면의 화면 차이는 명령 글꼴 대체로 인한 위치 차이였으며, 전체 화면을 비교하고 영상·원본 해시에 묶어 근거를 기록했다. 확인되지 않은 누락을 실제 버그로 보고하지 않는다.
- 16개 최신 대본과 실제 합성 PCM 2,223개를 바이트 단위로 대조해 자막 시각을 만들었다. 검수 페이지는 대본 클릭 이동, 자막, 시간별 의견 저장·JSON 내보내기를 지원한다. 국문·영문 브라우저 검사를 통과했다.
- 슬라이드는 국문 222장·영문 263장이며 차시별 전체 대본 8개씩을 추가로 내장했다. 두 언어의 자습 분권 40파일씩과 통합 워크북을 재생성했다. 모든 분권 파일은 100KB 이하다. 영어 첫 열기를 한국어로 바꾸던 런타임 오류도 수정했다.
- 자습 입력 검사는 이제 기본으로 저장소의 원본 8개를 찾으며 빈 입력을 성공으로 보고하지 않는다. 도해와 문서 틀까지 계산해 단계 경계로 분권한다. 120KB를 넘는 통합 JSON은 실제 분권 HTML의 100KB 상한을 검사한다. 내용·명령·입력값은 바꾸지 않았다.
- 렌더는 HyperFrames 0.8.36, 1080p/30fps, high 품질이다. 남은 렌더는 실험 캡처를 끄고 beginFrame 워커 4개로 프레임을 즉시 인코딩한다. 임시 디스크 부족을 피하며, 기존 완성 파일도 장면별 실제 인코딩 화면 대조 후 유지한다. 긴 통합 영상의 300개 표본으로 생긴 모션 오판은 기존 `prepare_scene_checks.py`로 모든 원래 단언을 보존한 170개 장면 검사로 확인한다.
- 독립 검토 후 자습 첫 열기의 암묵적 언어 저장, 안내 배너를 닫았을 때 전체 대본 접근, WebVTT 특수문자 표시를 수정했다. 양 언어 브라우저 검사와 전체 자막 2,223개의 글자 보존 검사를 통과했다. 최종 묶음 생성과 업로드는 MP4 16개·자막 내용/시각·전체 디코딩·장면별 음성/실제 화면 대조·170개 원본 장면 검사 완료를 요구한다.
- 자동 테스트 225개(root 7, part 167, selfstudy 41, Node 10), 과정 검사와 공개 자료 가드를 통과했다. 발음 보정 삭제 시 캐시된 보정 음성을 재사용하던 경우도 재현 후 수정했다. 현재 제작 음성은 그대로 보존했다.
- 국문 7차시 자막 왕복 검사에서 FFmpeg SRT 처리기가 AutoCAD 측정값 자리표시 `<>`를 제거하는 것을 발견했다. 원문을 바꾸지 않고 이스케이프된 VTT로 MP4 자막을 넣어 해결했다. 실제 16차시 2,223개 자막 모두 VTT→MP4→SRT 문자·시각 대조를 통과했다. MP4 내장 자막·VTT·검수 플레이어를 권장하고, 외부 SRT 재생기의 기호 해석 차이는 안내에 적었다.
