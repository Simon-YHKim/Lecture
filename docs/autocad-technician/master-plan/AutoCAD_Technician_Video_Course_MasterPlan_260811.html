01 / EXECUTIVE SUMMARY

한눈 요약

테크니션이 도면을 읽고, 기본 형상을 작성하며, 기존 설비·Layout 도면을 확인·수정할 수 있도록 구성한다. 기능 나열식 교육이 아니라 매 차시 하나의 실무 결과물을 완성하는 구조를 적용한다.

교육 대상

테크니션

CAD 입문자와 도면 열람 위주 사용자

교육 체계

4×10

4개 그룹, 10개 세부 차시

운영 시간

10~15분/차시

짧은 개념과 충분한 화면 실습

최종 성과

1개 완성 도면

교육용 센서 브래킷 2D 도면

추천 제작 방식
AutoCAD 실습 화면을 먼저 녹화하고 후시 음성을 입힌다. 자막·화면 확대·인트로·요약은 편집 단계에서 추가하며, 실제 설비 도면 대신 보안정보가 제거된 교육용 도면을 사용한다.
02 / LEARNING DESIGN

교육 설계 원칙

업무 상황 중심

“설비 간 거리 확인”, “브래킷 수정”, “체결 구멍 추가”처럼 현장에서 접하는 작업을 출발점으로 삼는다.

한 차시, 한 결과물

각 영상이 끝날 때 확인 가능한 도면 또는 수정 결과를 남겨 학습 성취도를 명확하게 한다.

오류 복구 포함

ESC, UNDO, Layer, Osnap, 기준점과 입력값 오류 등 초보자가 막히는 지점을 실습 중 함께 설명한다.

학습 흐름

도면 이해→작업환경 설정→기본 작도→정밀 작도→객체 편집→치수·측정→현장 도면 활용→종합 실습

교육 내용별 그룹 및 세부 차시

1. 도면 이해 및 작업환경총 22분 · 기초 이해와 실습 준비
1-1

테크니션을 위한 CAD 실무 활용과 도면 읽기

권장 10분 · 결과물: 도면 핵심정보 체크
도면 역할선 종류정투상도면 정보
주요 내용: CAD 활용 업무 사례, 도면명·단위·축척·주요 치수, 외형선·중심선·숨은선, 정면도·평면도·측면도 이해.
대표 대본

“이번 과정은 AutoCAD의 모든 기능을 배우는 과정이 아닙니다. 현장에서 도면을 확인하고 필요한 치수를 측정하며 간단한 형상을 작성하거나 수정하는 데 필요한 기능을 실습합니다.”

1-2

AutoCAD 화면 조작과 작업환경 설정

대표 대본

“먼저 실습 파일을 별도 이름으로 저장하겠습니다. 원본을 직접 수정하지 않는 습관이 중요합니다. Layer를 분리하면 필요한 정보만 표시하거나 선택할 수 있습니다.”

2. 기본 도면 작성총 42분 · 형상 작성과 정밀 수정
2-1

기본 형상 작성

“마우스로 대략 그리지 않고 치수와 기준점을 입력하겠습니다. 원을 작성할 때는 반지름과 지름 입력을 혼동하지 않도록 명령창을 확인합니다.”

2-2

거리·좌표·각도를 이용한 정밀 작도

절대좌표상대좌표극좌표각도 입력

대표 대본

“정확한 도면은 커서 감각이 아니라 입력값에서 나옵니다. 길이, 방향과 각도를 숫자로 입력해 같은 결과를 반복해서 만들 수 있어야 합니다.”

2-3

대표 대본

“실제 업무에서는 처음부터 다시 그리는 것보다 기존 형상을 수정하는 경우가 많습니다. 기준 형상은 유지하면서 필요한 부분만 정확히 바꾸겠습니다.”

3. 객체 편집 및 도면 완성총 39분 · 배치, 반복, 마감과 치수
3-1

객체 복사·이동·대칭·회전

대표 대본

“객체를 이동하거나 복사할 때 가장 중요한 것은 기준점입니다. 어떤 점을 잡았는지 명확하지 않으면 최종 위치도 정확하지 않습니다.”

3-2

반복 형상 작성과 세부 마감

대표 대본

“반복 형상을 하나씩 그리면 시간과 위치 오차가 늘어납니다. 기준 객체 하나를 정확히 만든 뒤 배열 기능으로 동일 간격에 배치하겠습니다.”

3-3

치수 기입과 도면 측정

대표 대본

“값만 확인할 때는 측정 명령을 사용하고 도면에 정보를 남겨야 할 때는 치수 명령을 사용합니다. 값이 예상과 다르면 단위와 Scale을 확인합니다.”

04 / STANDARD FORMAT

차시별 표준 영상 구성

구간권장 시간구성제작 포인트
업무 상황·완성 결과약 1분이번 작업의 필요성과 완성 형상 미리 보기학습 목적을 먼저 이해시킨다.
핵심 개념2~3분필요한 명령과 주의점만 설명기능 정의를 장황하게 설명하지 않는다.
강사 화면 실습6~8분명령어 입력, 기준점 선택, 결과 확인명령창과 입력값이 항상 보이게 한다.
교육생 따라 하기약 2분영상 일시정지 후 동일 과제 수행정지 아이콘과 완료 조건을 제시한다.
오류·정리1~2분대표 오류와 확인 체크리스트정상 결과와 오류 결과를 비교한다.

05 / VOICE & NARRATION

목소리 및 녹음 운영안

추천 톤

  • 강사가 직접 설명하는 차분한 실무형 목소리
  • 교육방송보다 옆에서 알려주는 선임 테크니션 느낌

08 / SECURITY & QUALITY

보안·촬영·품질 검수 기준

보안 원칙
