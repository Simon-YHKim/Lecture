04치수 여덟 항목The eight dimensions

도면 위 치수는 이 여덟 개가 전부입니다.

These eight entries are all the dimensions on the drawing.

치수를 왜 이렇게 꼼꼼히 읽을까요? 스페어 파트를 급히 만들어야 할 때가 있어요. 이 숫자를 그대로 가공집에 넘깁니다. 하나가 틀리면 물건이 안 맞아요.

Why read the dimensions this carefully? Because a spare sometimes has to be made in a hurry. These numbers go straight to the machine shop. One wrong number and the part does not fit.

여기서 헷갈립니다 This is where people slip

16 은 두께가 아닙니다. 정면에서 본 베이스의 높이예요. 두께는 평면도에서 읽습니다. 80 도 마찬가지예요. 그 자리에는 라운드가 있어 모서리가 실제로는 없습니다. 라운드가 지운 이론상의 모서리까지 잰 값이에요. 목 선은 이 점에서 시작합니다.

16 is not a thickness. It is the height of the base seen in the front view; thickness is read in the top view. The 80 is the same kind of trap. A fillet sits there, so the corner does not physically exist. The 80 runs to the theoretical corner the fillet erased. The web line starts from that point.

괄호 친 치수 A dimension in parentheses

필렛 중심의 가로 위치는 (95.7) 로 적혀 있습니다. 괄호는 참고 치수라는 뜻이에요. 다른 값에서 계산되어 나오는 값입니다. 그래서 그 자체를 검사 대상으로 삼지 않아요. 이 값이 어느 두 점 사이인지는 도면마다 다르게 잡습니다. 지금은 괄호의 뜻만 기억해 두세요.

The horizontal position of the fillet center is written as (95.7). Parentheses mark a reference dimension. It is derived from other values. So it is not inspected on its own. Which two points it spans is drawn differently from drawing to drawing. For now just remember what the parentheses mean.

스페어 파트 긴급 공수 Urgent spare-part sourcing

설비가 서면 이 여덟 항목을 그대로 옮겨 적어 가공집에 넘겨요. 어느 뷰에서 읽은 값인지까지 함께 적어 두세요.

When the line stops you copy these eight entries and hand them to the machine shop. Write down which view each value was read from as well.

The letters around the numbers are what specify the machining.

You have read the dimensions, so now read the symbols. All eight of them again. Read each one aloud once.

You talk to the machine shop in these symbols. Spell them out in words and the two of you hear different things. The symbols are the precise channel.

The sheet is A3 landscape, 420 x 297 mm.

You have finished reading the part. Now you set up to draw. The environment you build today is not only for this part. Once the sheet and the line rules are settled, you can start drawing anything straight away.

07레이어 네 개The four layers

외형선 · 중심선 · 숨은선 · 치수선, 넷뿐입니다.

Visible line, centerline, hidden line, dimension line - just four.

레이어는 선의 색상·선 종류·굵기를 묶음으로 정하는 장치입니다. 개체마다 하나씩 줄 필요가 없어요. 여기서 한 번 정해 두면 그 레이어에 그린 선이 값을 물려받습니다.

A layer sets color, linetype, and lineweight for a whole group. You never have to set them object by object. Settle them once here and every line drawn on that layer inherits them.

There are two kinds of number in that table. It is an easy place to slip, so look at it closely. Lineweight is the thickness of the line, in millimeters. Only the visible line is 0.30 and the rest are 0.15, exactly double. The shape has to reach your eye first on a printed drawing.

선 종류 축척은 두께가 아닙니다. 점선의 간격이에요. 그래서 값이 있는 줄이 중심선과 숨은선뿐입니다. Continuous 에는 조정할 간격이 없습니다. 화면에서 점선이 실선처럼 보이면 축척이 안 맞는 거예요. 도면 전체를 한꺼번에 맞추는 명령은 LTSCALE 입니다. 조정하는 방법은 뒤 차시에서 다룹니다. 지금은 값만 기억해 두세요.

Linetype scale is not thickness. It is the spacing of the dashes. That is why only the centerline and the hidden line carry a value; Continuous has no spacing to adjust. If a dashed line looks solid on screen, the scale is off. The command that adjusts the whole drawing at once is LTSCALE. How to use it comes in a later lesson. For now just remember the value.

The layer table on the Lesson 2 video screen has no lineweight column. Its linetype scales differ as well. This book uses the values from the master drawing specification. The table above is the reference.

과제 지시 우선 The assignment instruction wins

과제 지시가 다른 이름이나 색상, 축척을 지정할 수 있습니다. 그럴 때는 그 지시가 우선합니다. 여기 값은 연습용 기본값이에요. 지시를 먼저 확인하고, 어긋난 곳을 찾고, 고치고, 다시 검수합니다.

An assignment may specify different names, colors, or scales. When it does, the assignment wins. The values here are practice defaults. Check the instruction first, find what differs, fix it, and check again.

08명령을 끝내는 습관과 한/영 키Ending a command, and the Korean input key

초보가 잃는 시간의 절반은 이 둘에서 나옵니다.

Half the time a beginner loses goes to these two things.

오토캐드는 명령이 하나씩 돌아갑니다. 앞 명령이 안 끝났는데 새 명령을 치면 그 글자가 앞 명령의 답으로 들어가요. 「분명히 L 을 쳤는데 선이 안 그려진다」는 대부분 이겁니다.

AutoCAD runs one command at a time. Type a new command before the last one finished and your letters answer the old one. "I definitely typed L and no line appeared" is almost always this.

오늘의 Tip Tip of the day

`Esc` 로 끝내고 시작합니다. 무슨 상태든 Esc 를 누르면 명령이 취소되고 선택도 풀립니다. 잘 모르겠으면 두 번 누르세요. 점을 여러 개 받는 명령은 마지막에 엔터를 한 번 더 눌러야 끝나고, 아무 명령도 없을 때 누르는 엔터는 직전 명령을 다시 실행합니다. 그리고 한글 상태에서는 명령이 안 먹습니다. L 이 ㅣ 로, C 가 ㅊ 으로 들어가요. 명령행에 그런 글자가 보이면 한/영 키로 영문에 놓고 다시 칩니다. 문자 쓰기를 마쳤으면 Esc 로 끝내고 한/영 키를 되돌리는 것까지가 한 묶음이에요.

End with `Esc`, then start. Whatever state you are in, Esc cancels the command and clears the selection; press it twice if you are unsure. Commands that take several points need one more Enter at the end, and Enter on an empty command line repeats the last command. And commands do not work while Korean input is on: L arrives as a Korean letter. When you see that on the command line, switch back to English and retype. Ending text with Esc and switching the key back is one single habit.

09점을 찍는 네 가지 방법Four ways to place a point

마우스로 잡는 것이 먼저이고, 좌표는 잡을 것이 없을 때 씁니다.

Catching it with the mouse comes first; coordinates are for when there is nothing to catch.

AutoCAD가 「점을 지정하십시오」라고 물을 때 답하는 방법은 넷입니다. 기본은 마우스예요. 이미 그린 것에 스냅으로 붙이거나, 방향을 고정하고 거리만 칩니다. 좌표는 붙일 것이 아직 없을 때, 그리고 도면이 원점 기준 값을 직접 줄 때만 씁니다.

When AutoCAD asks you to specify a point there are four ways to answer, and the mouse leads. Snap onto something already drawn, or lock a direction and type only the distance. Coordinates are for when there is nothing to snap to yet, and for values the drawing states from the origin.

Is this point tied to a dimension? If it is, type a coordinate or catch it with a snap; placing it by eye is not allowed, because two points that look identical on screen can hold different values. If it is not tied to anything, click. Memorising coordinates for those points only slows your hands down.

정확해야 하는 점 — 오늘

Must be exact — today

베이스 네 꼭짓점, 보스 중심, 목이 시작하는 두 점, 보스 원에 닿는 두 접점. 사각형은 REC 의 치수 옵션으로 세우고 나머지는 전부 스냅과 추적으로 잡습니다.

The four base corners, the boss centre, the two web feet and the two tangent points. The rectangle goes in through the Dimensions option of REC; everything else comes off the geometry by snap and tracking.

눈대중이어도 되는 점 — 오늘

By eye is fine — today

중심선이 형상 밖으로 나오는 길이(3에서 5 사이면 됩니다), 줌 윈도우의 두 구석. 도면에 기입되지 않는 값이라 클릭으로 잡아도 그만이에요.

How far the centerlines overrun the shape — anything from 3 to 5 works — and the two corners of the zoom window. Neither goes on the drawing, so clicking is fine.

스냅이 뜨는지부터 봅니다 Watch for the marker

스냅으로 잡을 때는 클릭보다 표식이 먼저입니다. 커서를 대상 위에 올리고 원하는 표식이 뜬 것을 보고 나서 누릅니다. 표식이 안 뜨면 F3 으로 객체 스냅을 켜고, 원하는 종류가 OS 목록에 체크돼 있는지 봅니다. 표식을 안 보고 누르면 근처의 다른 점이 잡혀요.

With a snap the marker comes before the click. Hover over the target, see the marker you want, then press. If nothing appears, turn object snap on with F3 and check that the kind you need is ticked in the OS list. Click without looking and you catch some other point nearby.

절대좌표는 도면에 원점 기준으로 위치가 적혀 있을 때만 씁니다. 용지선 두 구석이 그렇습니다. 그 밖에는 쓰지 않아요 — 원점이 어디인지 화면에 안 보이니 값이 맞는지 눈으로 확인할 수가 없습니다.

Absolute coordinates are for the few places the drawing states a position from the origin - the two sheet corners here. Nowhere else: the origin is not on screen, so you cannot see whether the number landed where you meant.

나머지는 전부 마우스와 숫자입니다. 방향은 커서가 정하고, 거리만 숫자로 줍니다. 기계 도면의 치수는 대부분 「여기서 저기까지 얼마」라서, 도면에 적힌 숫자가 그대로 입력값이 돼요. 계산을 안 하면 계산 실수도 없습니다. 게다가 그리는 동안 도형이 미리 보이니 틀렸으면 누르기 전에 압니다.

Everything else is the mouse and a number. The cursor sets the direction; you type only the distance. Mechanical dimensions mostly read from here to there is this much, so the printed number goes straight in. No arithmetic means no arithmetic mistakes - and the shape previews as you go, so a wrong value shows before you commit it.

골뱅이는 왜 안 쓰나 Why no @

상대좌표라는 표기가 있습니다. 앞에 골뱅이를 붙여 @120,0 처럼 씁니다. 앞에 찍은 점에서 얼마 갔는지를 적는 방식이에요. 이 과정에서는 쓰지 않습니다. 부호를 한 번 틀리면 반대로 그려지는데 화면을 봐도 왜 틀렸는지 모르고, 45도 모따기 같은 곳에서는 도면에 없는 계산값을 만들어 내야 합니다. 직교로 방향을 잡고 거리만 치면 부호가 아예 없어요.

There is a notation called a relative coordinate, written with an @ as in @120,0: how far you went from the point before. This course does not use it. One wrong sign draws the opposite way and the screen does not tell you why, and at a 45-degree chamfer it forces you to compute values the drawing never states. Lock the direction with ortho and type the distance, and there is no sign to get wrong.
