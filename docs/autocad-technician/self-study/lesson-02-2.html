08명령을 끝내는 습관과 한/영 키Ending a command, and the Korean input key

초보가 잃는 시간의 절반은 이 둘에서 나옵니다.

Half the time a beginner loses goes to these two things.

오토캐드는 명령이 하나씩 돌아갑니다. 앞 명령이 아직 안 끝났는데 새 명령을 치면 그 글자가 앞 명령의 답으로 들어가요. 「분명히 L 을 쳤는데 선이 안 그려진다」는 대부분 이겁니다.

AutoCAD runs one command at a time. Type a new command before the last one has finished and your letters are read as an answer to the old one. "I definitely typed L and no line appeared" is almost always this.

명령을 끝내는 Esc

Esc ends it

무슨 상태든 Esc 를 누르면 명령이 취소되고 선택도 풀립니다. 명령행이 비고 커서가 십자 모양으로 돌아와요. 다음 명령은 항상 이 상태에서 시작합니다. 잘 모르겠으면 두 번 누르세요.

Whatever state you are in, Esc cancels the command and clears the selection. The command line empties and the cursor goes back to a plain crosshair. Start every command from that state; press it twice if you are unsure.

한 번 더 누르는 엔터

The extra Enter

선이나 폴리선처럼 점을 여러 개 받는 명령은 마지막에 엔터를 한 번 더 눌러야 끝납니다. 그 엔터를 안 누르면 다음에 클릭하는 자리가 계속 그 선에 붙어요.

Commands that take several points - line, polyline - need one more Enter at the end. Skip it and every later click keeps extending that line.

빈 상태에서 누르는 엔터

Enter on an empty command line

아무 명령도 없을 때 엔터나 스페이스를 누르면 직전 명령이 다시 실행됩니다. 같은 명령을 연달아 쓸 때 편해요. 반대로 말하면, 끝난 줄 알고 누른 엔터가 명령을 다시 켜기도 합니다.

With nothing running, Enter or the space bar repeats the last command. Handy when you use one command several times running - and also how a stray Enter restarts a command you thought was over.

한/영 키 — 명령이 한글로 들어갑니다 The Korean input key eats commands

한글 입력 상태에서 L 을 치면 ㅣ 가, C 를 치면 ㅊ 이 들어갑니다. 명령행에 그런 글자가 보이면 한/영 키를 눌러 영문으로 바꾸고 다시 치세요. 문자 쓰기(DTEXT)를 하다가 한글로 바꿔 둔 채 그대로 명령을 치는 것이 가장 흔한 경우입니다. 문자를 다 넣었으면 Esc 로 끝내고 한/영 키를 영문으로 되돌리는 것까지가 한 묶음이에요.

With Korean input on, L arrives as ㅣ and C as ㅊ. When you see letters like that on the command line, switch back to English with the Korean/English key and retype. The usual cause is writing text with DTEXT, leaving the input mode in Korean, and typing the next command straight into it. Make ending the text with Esc and switching the key back one single habit.

명령행을 읽는 습관 Read the command line

명령행은 오토캐드가 지금 무엇을 묻고 있는지 적어 두는 자리입니다. 「첫 점 지정」이 떠 있으면 점을 찍어야 하고, 대괄호 안의 글자는 고를 수 있는 옵션이에요. 화면만 보고 마우스를 움직이면 무엇을 묻는지 모른 채 클릭하게 됩니다. F2 를 누르면 지나간 기록까지 큰 창으로 볼 수 있어요.

The command line is where AutoCAD writes down what it is asking. "Specify first point" means it wants a point; the letters in square brackets are options you may pick. Watch only the drawing and you click without knowing what was asked. F2 opens the full history in a larger window.

중심선에 CENTER, 숨은선에 HIDDEN 이 지정됐는가CENTER is on the centerline layer and HIDDEN on the hidden line layer두 칸이 Continuous 로 남아 있으면 6단계를 건너뛴 것입니다. 목록에 없으면 먼저 불러옵니다.If either still says Continuous, step 6 was skipped. Load the linetype first if it is missing.
현재 레이어가 외형선인가The current layer is the visible line layer화면 위 레이어 표시를 봅니다. 다른 이름이면 9단계로 돌아갑니다.Look at the layer indicator at the top. If it shows another name, go back to step 9.
파일 이름이 EDU-IB-02_L02_TEMPLATE 인가The file is named EDU-IB-02_L02_TEMPLATE하이픈과 밑줄 위치까지 같아야 합니다. 3차시는 이 파일을 열어 시작해요.Hyphens and underscore must match exactly. Lesson 3 opens this file to start.

01자가 점검Check yourself

먼저 답해 보고 펼치세요. 막히면 그 절로 돌아가면 됩니다.Answer first, then open. If you are stuck, go back to that section.

축 구멍은 곱게 다듬고 장공은 거칠어도 됩니다. 판단 기준은 무엇입니까?The bore is finished fine, the slots may stay rough. What is the criterion?
무엇이 닿느냐입니다. 축 구멍은 회전하는 축이 닿아 미끄럼 마찰이 계속됩니다. 장공은 볼트가 통과만 합니다. 볼트는 머리와 프레임 사이에서 눌러 잡습니다. 구멍 벽은 힘을 받지 않습니다. 필요 없는 곳을 곱게 하면 가공비만 오릅니다. 틀렸으면 「부위별 가공과 표면 거칠기」로 돌아가세요.What touches it. A rotating shaft runs in the bore, so sliding friction is continuous. A bolt only passes through the slot. It clamps between its head and the frame. The slot wall carries no load. Finishing a face that does not need it only raises the cost. If you missed this, go back to the machining section.
PCD Ø44 는 무엇의 지름입니까?Diameter of what is PCD Ø44?
탭 구멍 네 개의 중심이 놓이는 원의 지름입니다. 구멍 자체의 지름이 아닙니다. 여기서 헷갈리면 구멍이 엉뚱하게 커져요. 틀렸으면 「기호 여덟 개」로 돌아가세요.The circle the four tapped-hole centers sit on. It is not the diameter of the holes themselves. Confusing the two makes the holes far too large. If you missed this, go back to the symbols section.
16 은 판의 두께입니까?Is 16 the plate thickness?
아닙니다. 정면에서 본 베이스의 높이입니다. 두께는 평면도에서 읽고 판이 12, 보스가 있는 자리가 20 입니다. 틀렸으면 「치수 여덟 항목」으로 돌아가세요.No. It is the height of the base seen in the front view. Thickness is read in the top view: 12 for the plate and 20 where the boss is. If you missed this, go back to the dimensions section.
도면선을 용지선에서 사방 10 띄우는 이유는 무엇입니까?Why is the border set 10 mm inside the sheet outline on all four sides?
인쇄할 때 가장자리가 잘릴 수 있기 때문입니다. 잘려도 도면 내용은 살아 있어야 합니다. 틀렸으면 「A3 용지와 도면틀」로 돌아가세요.Because the edges can be cropped when printing. The content of the drawing has to survive that. If you missed this, go back to the A3 sheet section.
표제란에 이름을 넣었더니 물음표가 나왔습니다. 어느 단계로 돌아갑니까?Your name came out as question marks in the title block. Which step do you go back to?
13단계입니다. 문자 스타일의 글꼴이 아직 txt.shx 이기 때문이에요. 한글 자형이 없어 물음표가 나와요. 굴림 계열이나 whgtxt.shx 중 하나로 바꿉니다.Step 13. The text style font is still txt.shx. It has no Korean glyphs, so you get question marks. Change it to a Gulim-family font or to whgtxt.shx.
선가중치와 선 종류 축척은 무엇이 다릅니까?What is the difference between lineweight and linetype scale?
선가중치는 선의 두께이고 단위는 밀리미터입니다. 외형선만 0.5, 나머지는 0.25 입니다. 선 종류 축척은 점선의 간격이라 중심선과 숨은선에만 값이 있습니다. Continuous 에는 조정할 간격이 없어요. 틀렸으면 「레이어 네 개」로 돌아가세요.Lineweight is the thickness of the line in millimeters: 0.5 for the visible line and 0.25 for the rest. Linetype scale is the spacing of the dashes, so only the centerline and the hidden line carry a value. Continuous has no spacing to adjust. If you missed this, go back to the four-layer section.

02내 이름표를 뗀 빈 템플릿 한 벌A blank copy of the template with your name off

지금 만든 파일을 다른 이름으로 한 벌 더 저장하세요. 예를 들면 MY_A3_TEMPLATE 이에요. 그런 다음 표제란 오른쪽 칸의 사번을 지우고 빈 칸으로 둡니다. 현장에서 치구를 하나 그려 제안할 때 이 파일을 엽니다. 바로 시작할 수 있는 상태가 됩니다. 실습용 파일 EDU-IB-02_L02_TEMPLATE 은 손대지 않습니다. 3차시가 그 파일을 엽니다.

Save a second copy of the file you just made under another name, for example MY_A3_TEMPLATE. Then clear the employee-number cell in the title block and leave it blank. That copy is ready to open whenever you want to sketch a jig proposal on the job. Do not touch EDU-IB-02_L02_TEMPLATE itself - Lesson 3 opens that one.
