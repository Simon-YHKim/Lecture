02일부러 하나 틀리고 스스로 찾기Break one thing on purpose and find it

정리가 끝난 파일에서 일부러 하나를 틀려 봅니다. 중심선 하나를 골라 레이어를 외형선으로 바꾸면 흰 실선이 됩니다. Esc 로 선택을 풀고 눈으로 찾아보세요. 못 찾으면 QSELECT 로 도면층 = 중심선을 걸어, 선택 표시가 없는 자리를 찾습니다. MATCHPROP으로 제자리로 보냅니다. 이 왕복이 실제 도면에서 레이어 오류를 찾는 방식 그대로예요. 끝나면 저장하세요.

Break something on purpose in your cleaned-up file. Set one centerline's layer to visible-line; it turns white and continuous. Press Esc and try to spot it by eye. If you cannot, run QSELECT with layer = center and find where a centerline should be highlighted but is not. Send it back with MATCHPROP. That round trip is how layer errors get found on real drawings. Save when you are done.

스스로 채점하는 기준Grade yourself on

  • 바꾼 선을 눈으로 못 찾았더라도 QSELECT 의 개수로는 찾아냈습니다.Even if you could not spot the line by eye, the QSELECT count found it.
  • MATCHPROP으로 되돌린 뒤 그 선을 클릭하면 화면 위 레이어 표시가 중심선으로 나옵니다.After MATCHPROP, clicking that line shows the center layer in the indicator at the top.
  • 되돌린 선이 다시 빨간 파선으로 보이고 간격도 다른 중심선과 같습니다.The restored line shows as a red broken line again, with the same spacing as the other centerlines.
