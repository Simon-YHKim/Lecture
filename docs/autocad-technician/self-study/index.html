Ten self-contained HTML files: one index, eight lessons, and one shared shell (color, type, tables, diagram styles, script). The shell lives in one place and each lesson pulls it in - never copied. A page reads top to bottom like this. (1) Header - title, written and updated timestamps, and a checkpoint badge showing the file you open and the file you save. The badge stays pinned while you scroll. (2) Left-hand section list - section name plus estimated minutes. The current section is highlighted and finished ones dim slightly: the video's three reading states rendered as static hierarchy rather than animation, with the contrast kept low. A checkbox beside each section is the reader's own progress mark, stored in localStorage under a filename key with a memory fallback. (3) Body - no section longer than about one screen. Each operation step is a four-column row: what you type, what it asks, what you enter, what correct looks like. Below it sits a collapsed 'if it did not work, look here' block: symptom, cause, fix on the spot, and which step to return to if that fails. Collapsed, it does not interrupt a reader for whom everything is working. (4) A stop point ends every section - one line of judgement plus 'this is a good place to stop'. The button to the next section sits under that judgement, never above it. (5) Footer - previous and next lesson, and a link to this lesson's recovery note. A memo sidebar is pinned on the right, collapsed by default and overlaid rather than pushing the text: drag-select, click the floating Memo button, and the quotation is pinned; major blocks carry data-memo anchors. 'Copy memo as prompt' assembles quotation, location, and note. The Korean/English toggle sits at the top right and switches the whole document at once - both languages live in the same DOM, switched by data-lang, with the choice remembered in localStorage. A build check compares node counts between the two languages so no section ships half-translated; diagram labels carry both languages too. Printing hides the toggle, the section list, the memo sidebar, and the top banner, and expands every collapsed recovery block - some people will carry paper to the machine. No external libraries, no build step, no network: CSS, JS, and SVG are all inline. No more than three colors: text #111111, secondary #666666 and #A4A3A4, accent #C7004C, page #FFFFFF, surface #F5F5F3, rules #A4A3A4. Zero corner radius, 2 px borders, no shadows.
